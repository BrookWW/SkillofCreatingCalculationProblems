## Package structure

The reusable skill is in [paper-math-bench/SKILL.md](paper-math-bench/SKILL.md). It includes mathematical workflow references, local Python helpers, synthetic implementation tests, blank TeX/BibTeX templates, model-setting reference data, and invocation metadata. Research downloads, task caches, generated problem banks, model runs, and private source banks belong outside the distribution.

The [task settings](paper-math-bench/references/execution/task-settings.md) define English intake and clarification questions and suggested options. Raw user instructions and replies remain in their original language. The [statement-style guide](paper-math-bench/references/research/statement-style.md) provides reusable design guidance without a worked problem bank.

## Requirements

Use Python 3.10 or later for the bundled helpers and tests. They use the Python standard library. Real evaluation additionally requires a compatible Codex CLI with the exact selected model, reasoning effort, and requested budget support. Unsupported settings stop without substitution. TeX compilation requires the document toolchain available in the execution environment.

## Local checks

From the repository root, run:

```sh
PYTHONPYCACHEPREFIX=/tmp/paper-math-bench-pycache \
  python3 -m unittest discover -s paper-math-bench/tests -v
```

Tests use temporary directories and synthetic parser, arithmetic, configuration, review, scoring, and process-control fixtures. Fake solver executables verify runner behavior; the suite does not launch paid model trials or require a private research bank. Set a cache prefix outside the repository to keep generated bytecode out of the package.

Check relative Markdown links, linked contents, package-relative assets, and frontmatter when editing documentation. Preserve the exact-version independent statement review and formal-test gates. Keep the default `gpt-5.6-sol / max` configuration unless the user explicitly selects another setting.

## Optional bank check

The generic local bank export check is skipped unless an existing bank is explicitly supplied through `PAPER_MATH_BENCH_TEST_BANK`:

```sh
PAPER_MATH_BENCH_TEST_BANK=/absolute/path/to/main.tex \
  PYTHONPYCACHEPREFIX=/tmp/paper-math-bench-pycache \
  python3 -m unittest discover -s paper-math-bench/tests -v
```

This opt-in check reads the supplied bank and exports only into its temporary test directory. It does not add the bank to the distribution. Keep real research questions out of implementation fixtures.
